# Study Manager - Requirements

## 1. Project Overview
A web application to manage study schedules for tech job preparations. It tracks progress in various subjects and integrates with coding platforms.

## 2. Core Features

### 2.1 Curriculum Management
- **Subjects**:
  - DSA (Data Structures & Algorithms)
  - CP (Competitive Programming)
  - AI (Artificial Intelligence)
  - Core CS: OS, OOPS, DBMS, CN
  - System Design: LLD, HLD
  - DevOps
  - Custom subjects
- **Progress Tracking**:
  - Visual indicators for each subject.
  - Topic-wise breakdown (e.g., Arrays, Graphs, Process Management).

### 2.2 Task Scheduler (Daily Planner)
- **Configurable UI**: User can set preferences for daily workload.
- **Auto-assignment**:
  - Daily learning tasks (articles, videos, documentation).
  - Daily problem-solving tasks (LeetCode, Codeforces).
- **Calendar/Timeline View**: Weekly and monthly views.

### 2.3 Platform Integration
- **LeetCode**:
  - Profile stats (Solved count, ranking).
  - Fetch questions (Daily Challenge, Random, Tag-specific).
- **Codeforces**:
  - Profile stats (Rating, solved count).
  - Fetch problems based on rating/tags.

### 2.4 User Interface
- **Dashboard**:
  - "At a glance" view of today's tasks.
  - Activity heatmap (like GitHub/LeetCode).
  - Streaks and gamification elements.
- **Configurable Settings**:
  - Daily time commitment.
  - Focus areas (e.g., "Focus on Graphs this week").

## 3. Future Scope
- Mock Interview scheduler.
- Peer matching for study.
- Resources repository (links to best articles/videos).
